# mark it down - Feature List

A modern, lightweight, and powerful Markdown editor and reader designed for speed and aesthetics.

## 🖋️ Editing & Preview
- **Real-time Rendering:** Instantly see your Markdown rendered as you type.
- **Multiple Modes:**
  - **Reading:** Pure focus on content.
  - **Editing:** Full-screen editor for deep work.
  - **Split View:** Side-by-side editor and preview.
  - **Sync View:** Synchronized scrolling between editor and preview.
- **Rich Toolbar:** Quick access to bold, italics, headers, lists, code, links, tables, and indentation.

## 📁 File Management
- **Native File System Access:** Open and save files directly to your local disk (in supported browsers).
- **Advanced Drag & Drop:** 
  - Drop single or multiple `.md` files to open.
  - Drop entire folders to maintain relative asset paths (images, etc.).
  - Smart `README.md` detection when dropping folders.
- **PWA Ready:** Installable as a desktop or mobile app with offline support via Service Workers.

## 🎨 Personalization & UI
- **Themes:** Three distinct modes: **Light**, **Dim**, and **Dark**.
- **Accent Colors:** Choose from Blue, Green, Mauve, Pink, Red, and Peach.
- **Typography:**
  - Multiple font families: Sans-serif, Serif, Cursive, and Monospace.
  - Adjustable font size (12px to 32px).
- **Table of Contents (TOC):** Automatically generated sidebar navigation based on your headers.
- **Visual Link Cues:** Optional toggle to distinguish between web links, local files, and anchor points.

## ⌨️ Productivity
- **Keyboard Shortcuts:**
  - `Cmd/Ctrl + S`: Save file.
  - `Cmd/Ctrl + Shift + S`: Save as.
  - `Cmd/Ctrl + O`: Open file.
  - `Cmd/Ctrl + Enter`: Toggle between Edit and Read modes.
- **Responsive Design:** Optimized for all screen sizes, featuring a draggable resizer for split views.
