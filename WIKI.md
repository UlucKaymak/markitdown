# 🎲 Markitdown Wiki

**Markitdown**, sadelik ve odaklanma odaklı, modern web teknolojileriyle (Tauri + React) geliştirilmiş, cross-platform (Windows & macOS) bir Markdown editörüdür.

---

## 🚀 Temel Özellikler

- **Dual-Mode Experience:** 
  - **Reading Mode:** Tam genişlikte, dikkati dağıtmayan temiz tipografi.
  - **Editing Mode:** Yazarken anlık önizleme (Live Preview) sunan split-screen deneyimi.
- **Table of Contents (ToC):** `TAB` tuşuna basarak sağdan açılan akıllı içindekiler paneliyle uzun dökümanlarda hızlı navigasyon.
- **Smart Links:** Markdown dosyaları arasındaki bağlantıları tanır ve uygulama içinde gezinmenizi sağlar.
- **Document Stats:** Kelime, karakter ve satır sayısını anlık olarak takip edin (Ayarlardan gizlenebilir).
- **Muted Aesthetic:** Gözü yormayan "Nord" ve "Sepia" gibi yumuşak renk temaları.

---

## ⌨️ Klavye Kısayolları

Uygulamanın gücü, elinizi klavyeden kaldırmadan her şeyi yönetebilmenizdedir.

| Kısayol | İşlev |
| :--- | :--- |
| `CMD + Enter` | **Reading / Editing** modları arasında hızlı geçiş |
| `CMD + S` | Kaydet (Save) |
| `CMD + Shift + S` | Farklı Kaydet (Save As) |
| `CMD + O` | Dosya Aç (Open) |
| `TAB` | **Table of Contents** panelini aç/kapat |
| `CMD + B` | **Kalın** (Bold) metin ekle |
| `CMD + I` | *Eğik* (Italic) metin ekle |
| `CMD + 1, 2, 3` | Başlıklar (H1, H2, H3) ekle |
| `CMD + R` | Dosyayı Yeniden Yükle (Reopen) |

## 🎨 Özelleştirme

Sağ alttaki **SETTINGS** butonuna basarak veya kısayollarla uygulamayı kendine göre uyarla:

- **Themes:** Light (Aydınlık), Dark (Karanlık), Nord (Mavi-Gri) ve Sepia (Eski Kağıt).
- **Accent Colors:** Mavi, Yeşil, Mor ve Kırmızı arasından ruh haline uygun vurgu rengini seç.
- **Typography:** Yazı boyutunu (12px - 32px) ve font ailesini (Sans, Serif, Mono) anlık olarak değiştir.

## 🛠 Teknik Altyapı

- **Frontend:** React (TypeScript) + Tailwind CSS 3
- **Backend:** Rust (Tauri v2)
- **Parser:** React-Markdown
